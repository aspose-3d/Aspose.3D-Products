Gli sviluppatori possono utilizzare la libreria 3D per estrarre facilmente gli asset dei file 3D. Pochi formati supportati dall'API sono WavefrontOBJ, Discreet3DS, STL (ASCII, Binario), FBX (ASCII, Binario), Universal3D, Collada, GLB, glTF, PLY, DirectX, formati Google Draco, ecc. Il processo di estrazione è semplice, carica il file sorgente tramite un'istanza della [classe scena](https://apireference.aspose.com/3d/net/aspose.threed/scene), crea la classe archivio e gestisci la classe di estrazione asset, e chiama Il metodo Salva per il parametro di formato di output pertinente.

{{% blocks/products/pf/feature-page-section  h2="Estrai Asset da Scena 3D in vari formati" %}}
Gli sviluppatori possono facilmente estrarre asset da file 3D tramite lo stesso processo elencato sopra. Considera alcuni esempi come **Estrattore 3DS in FBX**. Carica file 3DS tramite oggetti di classe scena. Crea opzioni di salvataggio con [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) per creare opzioni di salvataggio e chiama il metodo di salvataggio della scena con gli argomenti del percorso del file di output e le opzioni fbx. L'API dispone di classi di opzioni appropriate per il salvataggio in classi correlate, ad esempio [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) e altro ancora. Ecco l'elenco completo dei formati [estrattori](https://apireference.aspose.com/3d/net/aspose.threed.formats) 3D opzioni.
