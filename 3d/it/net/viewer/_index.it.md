{{% blocks/products/pf/feature-page-summary %}}
Gli sviluppatori possono utilizzare la libreria di grafica 3D per leggere, creare, trasformare, aggiornare e controllare facilmente i contenuti in formati 3D. Pochi formati supportati dall'API sono WavefrontOBJ, Discreet3DS, STL (ASCII, Binario), FBX (ASCII, Binario), Universal3D, Collada, GLB, glTF, PLY, DirectX, formati Google Draco, ecc. Il processo di visualizzazione è molto semplice, carica il file sorgente tramite un'istanza della [classe scena](https://apireference.aspose.com/3d/net/aspose.threed/scene), e chiama il metodo Salva con i parametri di formato di output rilevanti.

{{% blocks/products/pf/feature-page-section  h2="Visualizza la Scena 3D in vari formati" %}}
Gli sviluppatori possono facilmente visualizzare i file 3D tramite lo stesso processo elencato sopra. Considera alcuni esempi come **visualizzazione da 3DS a HTML5**. Carica i file 3DS tramite oggetti di classe scena. Crea opzioni di salvataggio utilizzando [Html5SaveOptions ](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) per creare opzioni di salvataggio e chiama il metodo salva scena con gli argomenti del percorso del file di output e le opzioni html5. L'API dispone di classi di opzioni appropriate per il salvataggio in classi correlate, ad esempio [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) e altro ancora. Ecco l'elenco completo delle opzioni di [visualizzatore di formati 3D](https://apireference.aspose.com/3d/net/aspose.threed.formats).
