{{% blocks/products/pf/feature-page-summary %}}
開発者は、3D グラフ ライブラリを使用して、3D 形式のコンテンツを簡単に読み取り、作成、変換、更新、制御できます。 API でサポートされている形式には、WavefrontOBJ、Discreet3DS、STL (ASCII、Binary)、FBX (ASCII、Binary)、Universal3D、Collada、GLB、glTF、PLY、DirectX、Google Draco 形式などがあります。 ビューイング プロセスは非常に簡単で、[シーン クラス](https://apireference.aspose.com/3d/net/aspose.threed/scene) のインスタンスを通してソース ファイルをロードし、関連する出力形式パラメータで Save メソッドを呼び出します。

{{% blocks/products/pf/feature-page-section  h2="3D シーンをさまざまな形式で表示" %}}
開発者は、上記と同じプロセスで簡単に 3D ファイルを表示できます。 **3DS から HTML5 ビューア** のような例を検討してください。シーン クラス オブジェクトを介して 3DS ファイルをロードします。 [Html5SaveOptions ](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) を使用して保存オプションを作成し、出力ファイル パスと html5 オプション引数でシーンの保存メソッドを呼び出します。 API には、関連するクラスに保存するための適切なオプション クラスがあります。たとえば、[A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) などがあります。 3D [ビューア形式](https://apireference.aspose.com/3d/net/aspose.threed.formats) の完全なリストを次に示します。
