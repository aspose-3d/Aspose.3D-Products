Desenvolvedores podem usar a biblioteca de gráficos 3D para ler, criar, transformar, atualizar e controlar facilmente o conteúdo em formatos 3D. Poucos formatos suportados pela API são WavefrontOBJ, Discreet3DS, STL (ASCII, Binário), FBX (ASCII, Binário), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco, etc. O processo de visualização é muito simples, carregue o arquivo de origem através de uma instância da [classe de cena](https://apireference.aspose.com/3d/net/aspose.threed/scene), e chame o método Save com os parâmetros de formato de saída relevantes.

{{% blocks/products/pf/feature-page-section  h2="Visualize Cena 3D para vários formatos" %}}
Desenvolvedores podem facilmente visualizar arquivos 3D através do mesmo processo listado acima. Considere alguns exemplos como **visualização de 3DS para HTML5**. Carregue arquivos 3DS via objetos de classe de cena. Crie opções de salvamento usando [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) para criar opções de salvamento e chame o método de salvamento da cena com os argumentos do caminho do arquivo de saída e as opções html5. A API possui classes de opções apropriadas para salvar em classes relacionadas, por exemplo, [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) e mais.
