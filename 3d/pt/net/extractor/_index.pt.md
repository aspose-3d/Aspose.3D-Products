Desenvolvedores podem usar a biblioteca 3D para extrair facilmente ativos de arquivos 3D. Poucos formatos suportados pela API são WavefrontOBJ, Discreet3DS, STL (ASCII, Binário), FBX (ASCII, Binário), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco formatos, etc. O processo de extração é simples, carregue o arquivo de origem através de uma instância da classe [scene](https://apireference.aspose.com/3d/net/aspose.threed/scene), crie a classe de arquivo e lide com a classe de extração de ativos e chame o Método Save para o parâmetro de formato de saída relevante.

{{% blocks/products/pf/feature-page-section  h2="Extrair Ativos de Cena 3D para vários formatos" %}}
Desenvolvedores podem facilmente extrair ativos de arquivos 3D através do mesmo processo listado acima. Considere alguns exemplos como **3DS para Extrator FBX**. Carregue arquivos 3DS via objetos de classe de cena. Crie opções de salvar com [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) para criar opções de salvamento e chame o método de salvamento da cena com os argumentos do caminho do arquivo de saída e opções fbx. A API possui classes de opções apropriadas para salvar em classes relacionadas, por exemplo [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) e mais.
