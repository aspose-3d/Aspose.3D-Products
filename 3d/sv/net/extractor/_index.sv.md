{{% blocks/products/pf/feature-page-summary %}}
Utvecklare kan använda 3D-biblioteket för att enkelt extrahera 3D-filassets. Några format som stöds av API:t är WavefrontOBJ, Discreet3DS, STL (ASCII, Binär), FBX (ASCII, Binär), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco-format, etc. Extraheringsprocessen är enkel, ladda källfilen via en instans av [scene class](https://apireference.aspose.com/3d/net/aspose.threed/scene), skapa arkivklassen och hantera extraheringsassetklassen, och anropa The Save-metod för det relevanta utdataformatparametern.

{{% /blocks/products/pf/feature-page-summary %}}

{{% blocks/products/pf/feature-page-section  h2="Extrahera Assets från 3D-scen till olika format" %}}
Utvecklare kan enkelt extrahera assets från 3d-filer genom samma process som anges ovan. Tänk på några exempel som **3DS till FBX Extractor**. Ladda 3DS-filer via scene class-objekt. Skapa spara alternativ med [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) för att skapa spara alternativ och anropa scene save-metoden med utdatafilsökvägen och fbx-alternativargumenten. API:t har lämpliga options-klasser för att spara till relaterade klasser, t.ex. [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) och mer. Här är hela listan över 3D [extractor formats](https://apireference.aspose.com/3d/net/aspose.threed.formats) alternativ.
