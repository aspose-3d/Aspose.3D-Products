開發人員可以使用 3D 圖形庫輕鬆讀取、建立、轉換、更新和控制 3D 格式中的內容。 API 支援的格式包括 WavefrontOBJ、Discreet3DS、STL（ASCII、二進位）、FBX（ASCII、二進位）、Universal3D、Collada、GLB、glTF、PLY、DirectX、Google Draco 格式等。 檢視過程非常簡單，透過 [scene 類別](https://apireference.aspose.com/3d/net/aspose.threed/scene) 的實例載入來源檔案，並使用相關的輸出格式參數呼叫 Save 方法。

{{% blocks/products/pf/feature-page-section  h2="將 3D 場景轉換為各種格式" %}}
開發人員可以透過上述相同的過程輕鬆檢視 3D 檔案。 考慮一些範例，例如 **3DS 轉換為 HTML5 檢視**。 透過 scene 類別物件載入 3DS 檔案。 使用 [Html5SaveOptions ](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) 建立儲存選項，並使用輸出檔案路徑和 html5 選項參數呼叫場景儲存方法。 API 針對儲存到相關類別提供適當的選項類別，例如 [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) 等等。 以下是完整的 3D [檢視器格式](https://apireference.aspose.com/3d/net/aspose.threed.formats) 選項清單。
