Los desarrolladores pueden usar la biblioteca de gráficos 3D para leer, crear, transformar, actualizar y controlar fácilmente el contenido en formatos 3D. Pocos formatos admitidos por la API son WavefrontOBJ, Discreet3DS, STL (ASCII, Binario), FBX (ASCII, Binario), Universal3D, Collada, GLB, glTF, PLY, DirectX, formatos Google Draco, etc. El proceso de visualización es muy simple, cargue el archivo fuente a través de una instancia de la [clase de escena](https://apireference.aspose.com/3d/net/aspose.threed/scene), y llame al método Save con los parámetros de formato de salida relevantes.

{{% blocks/products/pf/feature-page-section  h2="Ver Escena 3D a varios formatos" %}}
Los desarrolladores pueden ver fácilmente archivos 3D a través del mismo proceso que se enumera anteriormente. Considere algunos ejemplos como **visualización de 3DS a HTML5**. Cargue archivos 3DS a través de objetos de clase de escena. Cree opciones de guardado usando [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) para crear opciones de guardado y llame al método de guardado de la escena con los argumentos de la ruta de archivo de salida y las opciones html5. La API tiene clases de opciones apropiadas para guardar en clases relacionadas, por ejemplo [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) y más. Aquí está la lista completa de opciones de [visor de formatos 3D](https://apireference.aspose.com/3d/net/aspose.threed.formats).
