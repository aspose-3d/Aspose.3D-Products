{{% blocks/products/pf/feature-page-summary %}}
Vývojáři mohou snadno extrahovat 3D souborové aktiva pomocí 3D knihovny. Mezi podporované formáty API patří WavefrontOBJ, Discreet3DS, STL (ASCII, Binární), FBX (ASCII, Binární), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco formáty, atd. Proces extrakce je jednoduchý, načtěte zdrojový soubor prostřednictvím instance třídy [scene](https://apireference.aspose.com/3d/net/aspose.threed/scene), vytvořte třídu archivu a zpracujte třídu extrakce aktiva a zavolejte Metodu Save pro relevantní výstupní formátový parametr.

{{% blocks/products/pf/feature-page-section  h2="Extrahování aktiv ze 3D scény do různých formátů" %}}
Vývojáři mohou snadno extrahovat aktiva ze 3D souborů stejným procesem uvedeným výše. Zvažte některé příklady, jako je **3DS do FBX Extractor**. Načtěte soubory 3DS prostřednictvím objektů třídy scene. Vytvořte možnosti uložení s [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) pro vytvoření možností uložení a zavolejte metodu uložení scény s argumenty cesty k výstupnímu souboru a možnostmi fbx. API má vhodné třídy možností pro ukládání do souvisejících tříd, např. [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) a další. Zde je kompletní seznam 3D [formátů extraktorů](https://apireference.aspose.com/3d/net/aspose.threed.formats) možností.
