Les développeurs peuvent utiliser la bibliothèque 3D pour extraire facilement les actifs de fichiers 3D. Parmi les formats pris en charge par l'API, on trouve WavefrontOBJ, Discreet3DS, STL (ASCII, Binaire), FBX (ASCII, Binaire), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco, etc. Le processus d'extraction est simple : charger le fichier source via une instance de la [classe de scène](https://apireference.aspose.com/3d/net/aspose.threed/scene), créer la classe d'archive et gérer la classe d'extraction d'actifs, et appeler la méthode Save pour le paramètre de format de sortie pertinent.

{{% blocks/products/pf/feature-page-section  h2="Extraire les actifs de la scène 3D vers divers formats" %}}
Les développeurs peuvent facilement extraire les actifs des fichiers 3D grâce au même processus décrit ci-dessus. Considérez quelques exemples comme **Extracteur 3DS vers FBX**. Charger les fichiers 3DS via des objets de classe de scène. Créer des options d'enregistrement avec [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) pour créer des options d'enregistrement et appeler la méthode d'enregistrement de la scène avec les arguments du chemin du fichier de sortie et les options fbx. L'API dispose de classes d'options appropriées pour l'enregistrement dans des classes associées, par exemple [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) et plus encore.
