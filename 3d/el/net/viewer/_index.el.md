Οι προγραμματιστές μπορούν να χρησιμοποιήσουν τη βιβλιοθήκη γραφικών 3D για να διαβάσουν, να δημιουργήσουν, να μετασχηματίσουν, να ενημερώσουν και να ελέγξουν εύκολα το περιεχόμενο σε μορφές 3D. Λίγες μορφές που υποστηρίζονται από το API είναι WavefrontOBJ, Discreet3DS, STL (ASCII, Binary), FBX (ASCII, Binary), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco formats, κ.λπ. Η διαδικασία προβολής είναι πολύ απλή, φορτώστε το αρχείο πηγής μέσω μιας παρουσίας της [κλάσης σκηνής](https://apireference.aspose.com/3d/net/aspose.threed/scene), και καλέστε τη μέθοδο Αποθήκευση με τις σχετικές παραμέτρους μορφής εξόδου.

Οι προγραμματιστές μπορούν εύκολα να προβάλλουν αρχεία 3D μέσω της ίδιας διαδικασίας που αναφέρεται παραπάνω. Λάβετε υπόψη μερικά παραδείγματα όπως **3DS σε HTML5 προβολή**. Φορτώστε αρχεία 3DS μέσω αντικειμένων κλάσης σκηνής. Δημιουργήστε επιλογές αποθήκευσης χρησιμοποιώντας [Html5SaveOptions ](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) για να δημιουργήσετε επιλογές αποθήκευσης και να καλέσετε τη μέθοδο αποθήκευσης σκηνής με τα ορίσματα διαδρομής αρχείου εξόδου και html5. Το API διαθέτει κατάλληλες κλάσεις επιλογών για την αποθήκευση σε σχετικές κλάσεις, π.χ. [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) και άλλα.
