Οι προγραμματιστές μπορούν να χρησιμοποιήσουν τη βιβλιοθήκη 3D για να εξαγάγουν εύκολα περιουσιακά στοιχεία αρχείου 3D. Λίγες μορφές υποστηρίζονται από το API είναι WavefrontOBJ, Discreet3DS, STL (ASCII, Binary), FBX (ASCII, Binary), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco formats, κ.λπ. Η διαδικασία εξαγωγής είναι απλή, φορτώστε το αρχείο προέλευσης μέσω ενός στιγμιότυπου κλάσης [scene](https://apireference.aspose.com/3d/net/aspose.threed/scene), δημιουργήστε την κλάση αρχείου και χειριστείτε την κλάση περιουσιακού στοιχείου εξαγωγής, και καλέστε την Μέθοδος Αποθήκευση για την αντίστοιχη παράμετρο μορφής εξόδου.

Οι προγραμματιστές μπορούν εύκολα να εξαγάγουν περιουσιακά στοιχεία από αρχεία 3d μέσω της ίδιας διαδικασίας που αναφέρεται παραπάνω. Λάβετε υπόψη μερικά παραδείγματα όπως **Εξαγωγέας 3DS σε FBX**. Φορτώστε αρχεία 3DS μέσω αντικειμένων κλάσης σκηνής. Δημιουργήστε επιλογές αποθήκευσης με [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions) για να δημιουργήσετε επιλογές αποθήκευσης και να καλέσετε τη μέθοδο αποθήκευσης σκηνής με τα ορίσματα διαδρομής αρχείου εξόδου και επιλογών fbx. Το API διαθέτει κατάλληλες κλάσεις επιλογών για την αποθήκευση σε σχετικές κλάσεις, π.χ. [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) και άλλα.
