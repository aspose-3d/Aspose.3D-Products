Разработчики могут использовать 3D-графическую библиотеку для легкого чтения, создания, преобразования, обновления и управления содержимым в 3D-форматах. Несколько форматов, поддерживаемых API, включают WavefrontOBJ, Discreet3DS, STL (ASCII, Binary), FBX (ASCII, Binary), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco и другие. Процесс просмотра очень прост: загрузите исходный файл через экземпляр класса [scene](https://apireference.aspose.com/3d/net/aspose.threed/scene) и вызовите метод Save с соответствующими параметрами формата вывода.

{{% blocks/products/pf/feature-page-section  h2="Просмотр 3D-сцены в различные форматы" %}}
Разработчики могут легко просматривать 3D-файлы с помощью того же процесса, указанного выше. Рассмотрите несколько примеров, таких как **просмотр 3DS в HTML5**. Загружайте файлы 3DS через объекты класса scene. Создавайте параметры сохранения, используя [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) для создания параметров сохранения и вызова метода сохранения сцены с аргументами пути к выходному файлу и параметрами html5. API имеет соответствующие классы параметров для сохранения в связанные классы, например [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) и другие.
