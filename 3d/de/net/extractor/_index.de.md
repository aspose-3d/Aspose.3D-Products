{{% blocks/products/pf/feature-page-summary %}}
Entwickler können die 3D-Bibliothek verwenden, um 3D-Datei-Assets einfach zu extrahieren. Zu den von der API unterstützten Formaten gehören WavefrontOBJ, Discreet3DS, STL (ASCII, Binär), FBX (ASCII, Binär), Universal3D, Collada, GLB, glTF, PLY, DirectX, Google Draco Formate usw. Der Extraktionsprozess ist einfach: Laden Sie die Quelldatei über eine Instanz der [Scene-Klasse](https://apireference.aspose.com/3d/net/aspose.threed/scene), erstellen Sie die Archive-Klasse und behandeln Sie die Asset-Extraktionsklasse, und rufen Sie die Methode Save für den relevanten Ausgabeformatparameter auf.

{{% blocks/products/pf/feature-page-section  h2="Assets aus 3D-Szenen in verschiedene Formate extrahieren" %}}
Entwickler können Assets einfach aus 3D-Dateien durch denselben oben aufgeführten Prozess extrahieren. Betrachten Sie einige Beispiele wie **3DS zu FBX Extractor**. Laden Sie 3DS-Dateien über Scene-Klassenobjekte. Erstellen Sie Speicheroptionen mit [FbxSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/fbxSaveOptions), um Speicheroptionen zu erstellen, und rufen Sie die Scene-Speichermethode mit den Argumenten Pfad und FBX-Optionen für die Ausgabedatei auf. Die API verfügt über geeignete Optionsklassen zum Speichern in verwandten Klassen, z. B. [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) und mehr. Hier ist die vollständige Liste der 3D [Extraktorformate](https://apireference.aspose.com/3d/net/aspose.threed.formats) Optionen.
