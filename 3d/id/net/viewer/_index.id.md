{{% blocks/products/pf/feature-page-summary %}}
Pengembang dapat menggunakan pustaka grafik 3D untuk dengan mudah membaca, membuat, mengubah, memperbarui, dan mengontrol konten dalam format 3D. Beberapa format yang didukung oleh API adalah WavefrontOBJ, Discreet3DS, STL (ASCII, Biner), FBX (ASCII, Biner), Universal3D, Collada, GLB, glTF, PLY, DirectX, format Google Draco, dll. Proses penampilannya sangat sederhana, muat file sumber melalui instance kelas [scene](https://apireference.aspose.com/3d/net/aspose.threed/scene), dan panggil metode Save dengan parameter format output yang relevan.

{{% blocks/products/pf/feature-page-section  h2="Lihat Adegan 3D ke berbagai format" %}}
Pengembang dapat dengan mudah melihat file 3d melalui proses yang sama yang terdaftar di atas. Pertimbangkan beberapa contoh seperti **penampil 3DS ke HTML5**. Muat file 3DS melalui objek kelas scene. Buat opsi simpan menggunakan [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5SaveOptions) untuk membuat opsi simpan dan panggil metode simpan adegan dengan jalur file output dan argumen opsi html5. API memiliki kelas opsi yang sesuai untuk menyimpan ke kelas terkait, misalnya [A3dwSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/a3dwsaveoptions) [AmfSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/amfsaveoptions) [Discreet3dsSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/discreet3dssaveoptions) [Html5SaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/html5saveoptions) [RvmSaveOptions](https://apireference.aspose.com/3d/net/aspose.threed.formats/rvmsaveoptions) dan lainnya. Berikut adalah daftar lengkap opsi [penampil format](https://apireference.aspose.com/3d/net/aspose.threed.formats) 3D.
